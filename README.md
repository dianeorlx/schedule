# Telegram-бот для расписания студентов и преподавателей.

## Задача №1

Реализовать команды `/help`, `/info`.

## Задача №2

Сделать регистрацию с выбором роли (Студент/Преподаватель) и группы/кафедры, спроектировать БД для пользователей, ролей и расписаний, добавить вывод расписания и функцию полного удаления данных пользователя.

## Задача №3

Реализовать создание, изменение и отмену занятий с привязкой к дате и времени, вывод расписания на дату или диапазон, команду `/show` с Inline-кнопками навигации («Сегодня», «Завтра», «Неделя»), ввод местоположения при регистрации для определения часового пояса.

## Задача №4

реализовать управление списками групп и кафедр (добавление, редактирование, удаление), модерацию регистраций новых студентов, выдачу списка студентов по группе.
